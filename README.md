# ByeDPI Strategy Generator

Android-приложение для Android TV и Android-телефонов, которое создаёт текстовые конфиги-кандидаты ByeDPI с нуля.

## Возможности

- Неограниченное накопление партий кандидатов.
- Повторяемые наборы через seed.
- Размер партии начинается с 1 и увеличивается кнопками `+1`, `+10`, `+100`.
- Экспорт всех накопленных строк в `.txt`.
- Копирование всех накопленных строк в буфер обмена одной кнопкой.
- Проверка прямой доступности `https://www.youtube.com` по HTTPS.
- Интерфейс с навигацией D-pad и крупными элементами для Android TV.

Генератор не запускает VPN и не проверяет работоспособность стратегий. Рабочую линию нужно вручную проверить в своём ByeDPI-клиенте.

## Сборка

Нужны JDK 17+ и Android SDK API 36.

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```

Debug APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Формат

Экспорт содержит строки из опций split/disorder/fake:

```text
-s1+s -d3+s -r4 -An
```
